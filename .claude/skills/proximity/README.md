# proximity

Writes and audits cold email copy using the Proximity Method. Onboards from your website the first time, then you just say who the list is for.

## How to use

Ask in your own words:

> Write cold email copy for this list

You get back: Copy written to the method, or an audit of copy you already have.

## How to install

This folder came in a handoff bundle. See `START-HERE.md` at the top of the
bundle - copy this folder into `~/.claude/skills/` and restart Claude Code.
