# humanizer

Rewrites text so it stops reading as AI, without changing what it says. Based on Wikipedia's "Signs of AI writing": inflated claims, stock phrases, vague sourcing, repetitive structure.

## How to use

Ask in your own words:

> Rewrite this so it doesn't sound like AI

You get back: The same content, in prose that does not announce itself as machine-written.

## How to install

This folder came in a handoff bundle. See `START-HERE.md` at the top of the
bundle - copy this folder into `~/.claude/skills/` and restart Claude Code.
